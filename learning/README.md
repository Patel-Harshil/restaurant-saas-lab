# Learning Journal — Restaurant SaaS Lab

This is a living personal textbook, not a generic course — every chapter is grounded
in the real code in this repo, with actual file:line citations, not invented examples.
See [PLAN.md](../PLAN.md) for the full 10-day sprint and how this fits in.

**How this works:**
- Each chapter ends with two sections for you to fill in yourself: **My notes** (in
  your own words, whatever's worth keeping) and **Things I found hard** (flag it there
  or just ask — either way, the fix is to expand that chapter in place with a simpler
  explanation, not answer it once in chat and lose it).
- New chapters get added as the sprint progresses — one per day's learning milestone,
  roughly. Nothing here is final; it accumulates.

## Chapters

### Day 1 — foundations
1. [HTTP & REST Fundamentals](01-http-and-rest.md) — the request/response cycle, verbs, status codes, headers, what "REST" actually means
2. [Node.js & Express Fundamentals](02-nodejs-and-express.md) — the event loop, what Express adds over raw Node, middleware as a checkpoint chain
3. [React Fundamentals](03-react-fundamentals.md) — components, JSX, props vs state, hooks, controlled inputs, one-way data flow
4. [Authentication & Security Concepts](04-auth-concepts.md) — password hashing, JWT structure, JWT vs sessions vs OAuth tradeoffs
5. [JavaScript Async: Promises, async/await, and fetch](05-javascript-async.md) — why JS doesn't block, Promises, async/await as sugar

More chapters land here as later days add their learning milestones.
